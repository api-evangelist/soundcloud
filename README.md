# SoundCloud (soundcloud)

SoundCloud is a music and audio streaming platform with a developer REST API for tracks, users, playlists, search, comments, likes, and uploads. Authentication is OAuth 2.1 with PKCE; access tokens expire approximately every hour.

## APIs

### SoundCloud API
REST API for SoundCloud covering tracks (upload, metadata, stream), users (/me, profiles), playlists (CRUD), search (title/username/description), social (follow, like, comment), and audio playback. OAuth 2.1 with PKCE; supports Authorization Code and Client Credentials flows.
- **Base URL:** `https://api.soundcloud.com`
- **Docs:** https://developers.soundcloud.com/docs/api/guide
